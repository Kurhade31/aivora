# Aivora Product Roadmap

Aivora is engineered as an extensible knowledge operating system. This roadmap outlines current milestones and future development horizons.

## Current Release: v1.0.0 (Foundation)
- [x] Complete brand identity & bespoke SVG asset library
- [x] Interactive Knowledge Orbit Map (`/map`)
- [x] Find Your AI Stack architectural generator (`/stack`)
- [x] AI Model, Tool, and Framework explorers
- [x] AI Project Lab with hands-on code blueprints
- [x] AI Safety Center with real vulnerability mitigations
- [x] Prompt Engineering Lab with live compiler
- [x] Technical Glossary & Historical Timeline (1950-Now)
- [x] Local browser progress tracking & bookmarks
- [x] Vitest test suites and automated content validator

---

## Phase 2: Offline Semantic Search & Aivora Guide
- [ ] Client-side WebAssembly vector search for local embeddings directly in the browser
- [ ] "Aivora Guide": Local grounded QA assistant distinguishing knowledge base facts from model inference without external paid API keys
- [ ] Interactive Mermaid architectural diagram rendering on all architecture pages
- [ ] Extended Project Lab blueprints (e.g. Fine-tuning LoRA adapters on consumer hardware)

---

## Phase 3: Community & Cloud Synchronization (Optional)
- [ ] Optional account sign-in for cross-device bookmark and learning progress synchronization
- [ ] Verified community submissions for novel open-weights models and frameworks
- [ ] Interactive code execution sandboxes in WebContainers directly inside the browser
- [ ] Exportable system architecture blueprints (Terraform, Docker Compose, Kubernetes manifests)

---

## Phase 4: Native Tooling & Ecosystem Extensions
- [ ] Aivora CLI (`aivora search <query>`, `aivora stack build`) for terminal-first developers
- [ ] Model Context Protocol (MCP) server exposing Aivora knowledge directly to agent copilots
- [ ] Multi-lingual knowledge translation into Spanish, Japanese, and Mandarin
