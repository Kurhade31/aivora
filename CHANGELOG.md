# Changelog

All notable changes to the Aivora platform are documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-02-15

### Added
- **Interactive AI Knowledge Map (`/map`)**: Canvas with orbital positioning, category filtering, zoom/pan controls, and interactive node relationship inspector.
- **Find Your AI Stack (`/stack`)**: Interactive architectural generator factoring execution mode (API vs local), RAG needs, agentic loops, budget, and privacy tiers.
- **6-Layer Knowledge Architecture**: Concepts systematically split across Foundation, Mechanism, Ecosystem, Application, Trade-Offs, and Practice.
- **Ecosystem Explorers**:
  - Model Explorer (`/ecosystem/models`): Frontier, open-weights, and specialized reasoning models.
  - Tool Explorer (`/ecosystem/tools`): Categorized strictly by Job-to-be-Done.
  - Framework Explorer (`/ecosystem/frameworks`): Runtimes, inference libraries, and agent frameworks.
- **AI Project Lab (`/build`)**: Production projects with executable code snippets, architectures, and common pitfalls.
- **AI Architecture Library (`/build/architectures`)**: Data flow diagrams, execution actor tables, and security considerations.
- **Prompt Engineering Lab (`/build/prompt-lab`)**: Interactive prompt compiler with 7 core pillars and pattern templates.
- **AI Safety Center (`/safety`)**: Vulnerability mitigation guides with side-by-side vulnerable vs hardened code patterns.
- **AI Technical Glossary (`/glossary`) & Timeline (`/timeline`)**: Rigorous technical definitions and milestones from 1950 to 2025.
- **AI Career Map (`/careers`)**: Role breakdowns, required skills, and project portfolios without salary promises.
- **Global Knowledge Graph Search**: Keyboard-accessible (⌘K / Ctrl+K) modal searching across all entities.
- **Local Progress Tracking**: Local browser-based tracking for completed topics and learning path checklists.
- **Original Brand Assets**: Knowledge Orbit mark, wordmark, lockup, favicon, app icon, and OG social previews.
- **Automated Validation**: CI test suite and `pnpm content:validate` script.
