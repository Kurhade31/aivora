# Security Policy

## Reporting a Vulnerability

Aivora takes security and data confidentiality seriously. If you discover a security vulnerability in the Aivora website, dependencies, or recommended architectural patterns, please report it responsibly.

### How to Report
Please email security disclosures directly to `security@aivora.dev` (or open a confidential GitHub Security Advisory) with:
- Description of the vulnerability
- Steps to reproduce or proof-of-concept
- Affected components or versions

Please do NOT create public GitHub issues for sensitive unpatched vulnerabilities.

## Scope
- The Aivora Next.js web application
- Content injection vulnerabilities or Cross-Site Scripting (XSS)
- The execution sandboxes recommended in the AI Project Lab
- Dependency vulnerabilities (tracked via Dependabot and automated audits)

## Supported Versions
Only the latest release branch (`main`) receives active security patches.
